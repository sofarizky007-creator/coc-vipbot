PROSEDUR KONFIGURASI

Empat Langkah Menjalankan Bot

Dari mengunduh paket aplikasi hingga rotasi farming berjalan mandiri hanya membutuhkan waktu beberapa menit.

  1. 01

    Unduh .EXE & Aktifkan Lisensi

    Unduh paket COC-VIPBot-Setup.zip, lalu klaim Serial Key Trial Gratis 24 Jam melalui Server Discord atau Bot Telegram resmi kami.

  2. 02

    Atur Emulator ke 1600×900

    Setel resolusi LDPlayer atau MuMuPlayer ke 1600×900 (240 DPI). Klik tombol Scan di aplikasi bot untuk mengunci port ADB masing-masing emulator.

  3. 03

    Konfigurasi Army & Ambang Wall

    Tentukan jumlah slot pasukan pada menu Set Army, kemudian aktifkan Auto Upgrade Wall beserta batas minimal Gold/Elixir di More Option.

  4. 04

    Mulai Rotasi Otomatis

    Tekan Start. Bot akan menuntaskan jatah Ranked, beralih ke Farming, mengklaim Star Bonus, dan meng-upgrade Wall secara berkelanjutan.
